# Templater and QuickAdd Routing

Context selects templates.

```text
DevNotes/Inbox                     → Capture
Trust Issues/Workspaces/*          → Verification/Evidence
Execution/Workspaces/*             → Specification / Work Package / Progress
Vibes/Workspaces/*                 → Architecture / Tech Req / Design / Security
Schemes/Workspaces/*               → Data Model / Knowledge Model
Prömpter/Workspaces/*              → Prompt Contract
Fuck You Pay Me/Workspaces/*       → Business Operation
```

Recommended QuickAdd commands:

```text
New Workspace
Capture
New Specification
Record Decision
Start Research
Create Work Package
Create Handoff
Create Verification
Create Prompt Contract
Create Data Model
Create Business Operation
```

Software workspace bootstrap may create Project Home, PRD, Technical Requirements, Architecture, Design, Auth & Security, Knowledge Model, and Validation & Conformance. Non-software workspaces should not inherit useless software paperwork.
