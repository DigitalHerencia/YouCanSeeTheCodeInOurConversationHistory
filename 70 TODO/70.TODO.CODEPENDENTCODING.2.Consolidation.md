## Program Rules

- A Simple is one real file; its note is the knowledge representation of that file.
- Old docs are source material, not automatic authority. Owner approval is the canonicalization gate.
- Docs and Simples project one underlying model.
- Real source remains implementation authority; metadata describes relationships, constraints, transforms, ownership, and generation disposition.
- Encode required, permitted, conditional, prohibited, and invalid relationships.
- Backend/security architecture is derived deterministically; user configuration is limited to legitimate presentation/composition choices.
- Do not start Constitutor work before the demonstration, hardening, and catalog are ready.

## First Vertical Slice

Use **Database** to replace the decorative fixed-foundation card with real source, relationship controls, and actual implementation consequences. Use TanStack Router as interaction-density inspiration. Monaco is optional new work; Codebase Context Utility does not currently include it.
