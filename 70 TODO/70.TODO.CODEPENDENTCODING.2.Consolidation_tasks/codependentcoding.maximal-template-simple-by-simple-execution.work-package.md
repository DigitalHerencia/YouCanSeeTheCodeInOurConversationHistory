# Execute the Maximal Template one Simple at a time

**Priority:** P0  
**Phase:** Maximal Demo

## Outcome

Finish the public Maximal Template demonstration through a repeatable one-Simple-at-a-time canonicalization loop rather than a broad rewrite.

## Checklist

- [ ] Gather all relevant source material for each Simple responsibility.
- [ ] Identify contradictions, obsolete versions, and implementation evidence.
- [ ] Propose the canonical architectural contract and golden implementation shape.
- [ ] Obtain owner approval before marking anything canonical.
- [ ] Update the Simple record and canonical doctrine.
- [ ] Implement the demo/showcase version in the public Maximal Template.
- [ ] Prepare/collocate the hardened canonical implementation while context is fresh.
- [ ] Record relationships, constraints, tests, validation, and generation-readiness metadata.
- [ ] Verify the public demonstration and hardened behavior that actually matters.
- [ ] Incorporate navigation/handoffs, representative demo data, architecture explorer, components/UI catalog, and real Simple source pages.
- [ ] Spawn bounded implementation tasks per Simple only when that Simple reaches execution.

## Acceptance

- [ ] Each completed Simple has reconciled doctrine, owner-approved canonical status, demo source, hardened source/status, relationship metadata, and verification evidence.
- [ ] The public Maximal Template becomes a coherent architecture demonstration.
- [ ] Constitutor/generator work does not begin prematurely.
