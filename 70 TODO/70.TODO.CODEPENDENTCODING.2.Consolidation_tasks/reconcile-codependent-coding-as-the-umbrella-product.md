# Reconcile Codependent Coding as the umbrella product

**Priority:** P0  
**Phase:** Consolidation

## Outcome

Make Codependent Coding™ the umbrella product/repository, with Hipster Stack™, Maximal Template™, Loaded Vibes™, Docs/Simples, the Constitutor™, and Codebase Context Utility capabilities as parts of one system.

## Checklist

- [ ] Reconcile active governance with the approved umbrella-product direction.
- [ ] Define the target topology: one Next.js application, one root `app/`, no `src/`, packages only where independent distribution is real.
- [ ] Define ownership/boundaries for Hipster Stack, Maximal Template, Loaded Vibes, Docs/Simples, Constitutor, and Codebase Context Utility capabilities.
- [ ] Record the implementation order: source intake → Simple model/workbench → public Maximal Template one Simple at a time → hardening → catalog → Constitutor.
- [ ] Keep backend architecture deterministic/derived; presentation/composition is the configurable surface.
- [ ] Do not migrate/delete source repositories in this task.

## Acceptance

- [ ] Active governance no longer contradicts the umbrella-product model.
- [ ] One target repository/application topology is explicit.
- [ ] Product/component ownership and sequencing are unambiguous.
