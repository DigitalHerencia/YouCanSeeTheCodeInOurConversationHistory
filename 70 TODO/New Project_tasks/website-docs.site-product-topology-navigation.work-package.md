**Priority:** P0  
**Phase:** Information Architecture  
**Task status:** Backlog

## Outcome

Make the public site clearly communicate how Codependent Coding, Hipster Stack, Maximal Template, Simples, Ontologies, Constituter, Ordinary Object, and Loaded Vibes relate.

## Why This Exists

The visual/site spec defines brand identities while the master provides the authoritative topology. Visitors should not have to reverse-engineer the relationships from names.
