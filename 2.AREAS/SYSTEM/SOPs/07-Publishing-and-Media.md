# Publishing and Media SOP

## Blog

Blog content is long-form or evergreen creative work.

Suggested structure:

`2.AREAS/BLOG/Ideas`
`2.AREAS/BLOG/Drafts`
`2.AREAS/BLOG/Review`
`2.AREAS/BLOG/Scheduled`
`2.AREAS/BLOG/Published`

## Social

Social content is platform-oriented short-form content.

Suggested structure:

`2.AREAS/SOCIAL/Ideas`
`2.AREAS/SOCIAL/Drafts`
`2.AREAS/SOCIAL/Review`
`2.AREAS/SOCIAL/Scheduled`
`2.AREAS/SOCIAL/Published`

## Media

Keep reusable media separate from copy. Images, GIFs, memes, screenshots, and source assets should have explicit links to the content that uses them.

## Plugins

QuickAdd creates content records. Templater supplies content structure. Note Toolbar supplies publishing actions. Hearth surfaces calendars and queues. Bases provides filtered editorial views.

Do not add a second calendar/task system solely for publishing.

## Lifecycle

Idea → Draft → Review → Ready → Scheduled → Published → Archived.

Each transition is explicit and can be represented by Meta Bind state.
