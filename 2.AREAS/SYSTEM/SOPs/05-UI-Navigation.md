# UI and Navigation SOP

## Hearth dashboards

Home remains the clean default Hearth home: search, background, identity, and minimal navigation.

Command Center is the daily-driver workspace: today, yesterday review, deadlines, calendar, focus, next action, and standup.

Project Command Center uses one selected project at a time. It surfaces the selected project's milestones, phase Kanban boards, deadlines, tasks, standup context, project documents, resources, codebase, posts, and artifacts.

Code Lab surfaces Domains, Dev Cycles, Standards, Patterns, learning progression, and links into mounted code.

Zettelkasten surfaces Inbox, AI Threads, Clippings, Fleeting, Literature, processing actions, and recent connections.

Library surfaces notes, resources, tags, backlinks, graph, bookmarks, and Bases views.

Vault surfaces Git status, changes, history, activity, and vault statistics.

## Hearth card proposal

Home: search/navigation card only.

Command: Today Tasks, Due/Overdue, Daily Note, Standup, Focus/Next Action, Recent Changes.

Projects: Selected Project, Milestone Boards, Active RoadMaps, Active Tasks, Project Artifacts, Project Resources.

Code: Domains, Current Dev Cycle, Standards, Patterns, Learning Progress, Mounted CodeSpace link.

Zettelkasten: Inbox Count, Unprocessed AI Threads, Clippings, Fleeting/Literature counts, Capture actions, Recent Connections.

Library: Recent Notes, Resources, Tags, Backlinks, Bookmarks, Bases.

Vault: Git status, changed files, recent commits, vault statistics, activity heatmap.

## Note Toolbar model

Global: Home, Command Center, Search, QuickAdd, Daily Note, Git, Hearth.

Project: Project Home, New Task, New RoadMap, New Phase, Milestone Board, Artifacts, Resources, Codebase, Posts.

Daily: Yesterday, Today, Standup, Tasks, Weekly Review, Command Center.

Zettelkasten: Capture Inbox, AI Thread, Clipping, Fleeting, Literature, Process/Refactor, Promote to Resource.

Resources: Open Resource Index, New Resource, Backlinks, Tags, Archive.

Code Lab: Domain, Dev Cycle, Standard, Pattern, Lesson, Drill, Evidence, CodeSpace.

Blog/Social: New Draft, Review, Schedule, Publishing Calendar, Media, Archive.

System: Templates, SOPs, Bases, Plugin settings, Reconcile/Repair.

Archive: Restore, Move to active area, Search.

Editing toolbar: formatting, links, tables, code, refactor, callouts, Meta Bind/property actions.

Reading toolbar: open backlinks, outgoing links, graph, properties, related Bases, archive, edit.

## Workspace model

Use named Workspaces for Home, Command Center, Project, Code Lab, Knowledge, and Vault. Workspace state should support the same dashboard concepts rather than create alternate navigation systems.
