# Visual System SOP

## Theme direction

Use a dark, modern, restrained interface influenced by contemporary developer products: high information density, strong typography, subtle borders, translucent surfaces, and controlled vaporwave accents.

The visual system should remain readable before decorative.

## CSS layers

- reform-core: base vault normalization.
- mode-neo-modern: primary modern surface treatment.
- mode-vaporwave: accent layer.
- codex-vercel: Vercel-inspired spacing/contrast layer.
- callouts: semantic callout presentation.

Deprecated or overlapping mode snippets are not simultaneously enabled.

## Typography

Use the configured primary interface/text/monospace fonts consistently. Favor clear hierarchy, compact metadata, readable line length, and strong code differentiation.

## Icons

Iconic provides consistent folder/file icons.

Suggested semantic families:

Projects: kanban/briefcase
Areas: layers
Daily: calendar
Code Lab: code-2
Zettelkasten: brain/network
Library: library
Resources: book/archive
System: settings
Archive: archive

Plugin actions should use Lucide-style semantic icons rather than emoji.

## Callouts

Standard semantic callouts:

NOTE — neutral context
INFO — operational guidance
TIP — reusable technique
SUCCESS — completed/validated output
WARNING — risk or blocked state
DANGER — destructive/high-risk operation
DECISION — approved choice
TRACE — links between project objects
EVIDENCE — verification/proof
INPUT — required human input
OUTPUT — produced artifact
DEPENDENCY — blocking relationship
NEXT — next action

Callouts should clarify workflow state, not decorate ordinary prose.

## Workspace presentation

Home is visually quiet. Command Center is operational. Project and Code Lab are information-dense. Vault is diagnostic. Use workspaces to preserve those modes.
