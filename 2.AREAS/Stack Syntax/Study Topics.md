# TypeScript and Stack Syntax Topics

Use these topics to select drills that resemble real application work. Each practice session should write syntax from memory, compare it with a reference, and record the correction.

## TypeScript

- Typed functions and return types
- Type inference and narrowing
- Generics and reusable constraints
- Zod schemas and inferred types
- Result and error shapes

## Application Boundaries

- Fetchers and request/response contracts
- Server actions and validation
- React components, props, hooks, and event handlers
- Next.js App Router and Server/Client boundaries
- Prisma queries and transactions
- Neon/Postgres interactions
- Clerk authentication and authorization

- Browser-test flows with Playwright
