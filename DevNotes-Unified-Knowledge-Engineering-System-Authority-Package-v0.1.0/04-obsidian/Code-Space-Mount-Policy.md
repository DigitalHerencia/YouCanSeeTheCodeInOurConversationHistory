# Code Space Mount Policy

Target:

```text
_mounts/
├── CodependentCoding/
├── TheMaximalTemplate/
├── TheHipsterStack/
└── other-trusted-repos/
```

Rules:
- mount specific trusted repositories only;
- never mount the whole development drive;
- `_mounts/` is local-only and Git-ignored;
- durable notes preserve meaning/decision/spec/evidence, not source photocopies;
- Source Mirror deletion requires a pilot, classification report, and explicit approval.
