# Callout Semantics

Adopt the current vault vocabulary:

| ID | Meaning |
|---|---|
| truth | canonical/source-of-truth statement |
| decision | consequential decision |
| requirement | requirement that must hold |
| working | draft/unresolved |
| risk | material risk |
| blocked | cannot proceed |
| evidence | validation/proof |
| handoff | context transfer |
| spark | idea worth developing |
| deprecated | superseded/historical |

Callouts annotate content. Properties remain lifecycle/authority state.
