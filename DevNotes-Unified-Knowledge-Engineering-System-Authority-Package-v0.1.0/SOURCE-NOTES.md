## Included target architecture

The supplied architecture establishes:

- eight ChatGPT Project roles as eight human-facing bounded contexts;
- the knowledge-model stack as the shared intellectual grammar;
- Codependent Coding as the engineering kernel;
- projects/products as `workspace` facets;
- dot/normal/underscore naming semantics;
- no-delete migration;
- Obsidian as the interface that recomposes knowledge by role or workspace.
