# DevNotes™ Unified Knowledge & Engineering System — Authority Package

**Version:** 0.1.0  
**Status:** proposed authoritative redesign package  
**Migration posture:** overlay-first, no-delete

This package unifies:

- the eight ChatGPT Projects;
- DevNotes as the durable Obsidian knowledge system;
- The Codependent Coding™ WebApp Architecture as the shared engineering kernel;
- the philosophical/computer-science knowledge-model stack;
- Obsidian plugins, templates, properties, backlinks, Bases, Hearth, Meta Bind, Note Toolbar, Callout Studio, Code Space, and Git.

## Critical distinctions

- **Role folder** = primary responsibility owner.
- **workspace** = project/product facet.
- **system** = reusable doctrine/system identity.
- **namespace** = stable semantic identity.
- **dot prefix** = machine-oriented, not automatically more authoritative.
- **underscore prefix** = operational/interface support.
- **human folder** = durable human-readable knowledge.
