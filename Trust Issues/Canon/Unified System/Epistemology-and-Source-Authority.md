# Epistemology and Source Authority

> **Truth is fact-specific.**

| Fact | Primary authority |
|---|---|
| User intent / genuine decisions | user |
| Reusable engineering doctrine | accepted Codependent Coding canon |
| Workspace product behavior | accepted specification / decision |
| Actual implementation | live repository |
| GitHub Issue / PR / branch / Actions state | GitHub |
| Deployment | deployment provider + verification |
| Calendar | calendar |
| Email | mailbox |
| Financial/account facts | financial provider |
| Application domain state | application database/domain |
| Verification result | executed Trust Issues evidence |
| Durable institutional memory | DevNotes canonical artifact |
| Deterministic architecture rule | machine projection of controlling canon |

Conflict resolution:

```text
identify fact class
→ identify authority
→ inspect provenance
→ inspect current evidence
→ reconcile
→ record decision/evidence
→ synchronize human + machine representation if doctrine changed
```

`inferred` is never equivalent to executed `passed`.
