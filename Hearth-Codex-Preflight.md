# Hearth Preflight Checklist

Before opening Codex with implementation credit:

- [ ] Put the Notion export in the build workspace.
- [ ] Ensure the CodependentCoding repo/Maximal Template is mounted and readable.
- [ ] Ensure Book of Knowledge and Book of Implementation are readable.
- [ ] Place the Hearth v0.4 package beside the vault repo or in the Codex working directory.
- [ ] Give Codex the `Hearth-Codex-GOAL.md` contents as the primary task instruction.
- [ ] Keep the existing vault Git history intact; do not reset the repository.
- [ ] Have Codex create a feature branch before modifying the vault.
- [ ] Require verification before merge/commit.
