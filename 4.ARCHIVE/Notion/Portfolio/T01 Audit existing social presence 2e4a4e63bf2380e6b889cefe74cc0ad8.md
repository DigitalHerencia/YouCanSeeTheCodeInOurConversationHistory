---

## **1. Executive Summary**

Digital Herencia already has **real infrastructure**, not cosplay. The website and GitHub together establish legitimate technical credibility. What’s missing is **signal consolidation** and **intentional audience routing**.

Right now:

- You look **credible to engineers**
- You look **invisible to clients, partners, and local ecosystem**
- Your personal identity and studio identity are not yet fused into a single, authoritative narrative

This is not a rebuild problem. It’s a **coordination problem**.

## **2. Asset-by-Asset Audit**

---

**Strong. Canonical. Keep.**

- Clear signal that this is an **IP-producing studio**, not a freelancer dumping snippets

### What’s Missing

- GitHub bio and README content are **under-leveraged as marketing**
- No explicit linkage to:
    - Las Cruces / New Mexico
    - DigitalHerencia website
    - You as founder-operator

### Recommendation

Treat GitHub as:

> The technical ledger of record
> 

Actions:

- Update org bio and key repo READMEs to include:
    - “Digital Herencia — Software Studio based in New Mexico”
    - Link to website
    - Founder attribution: Ivan P. Roman

No fluff. One paragraph. Done.

## **B. Website — digitalherencia.vercel.app (Brand Home)**

### Status

**Solid foundation. Needs amplification, not redesign.**

### What Works

- Professional visual execution
- Clear service offerings
- Studio framing instead of “hire me” energy
- Tech stack transparency builds trust
- Portfolio + blog structure already in place

### Weaknesses

- Blog appears underutilized or empty
- Social links exist but don’t yet terminate into *active* channels
- Local SEO is implicit, not explicit

### Strategic Role

The site should be:

> The canonical narrative + conversion hub
> 

Not a portfolio. Not a résumé. A studio headquarters.

### Recommendations

- Add 3–5 short, high-signal posts:
    - Studio mission
    - One flagship project case study
    - One “how we think about software” post
- Add explicit geographic language:
    - “New Mexico-based”
    - “Southwest software studio”
- Ensure all social links route to *live, maintained* profiles only

## **D. Facebook — Personal Profile**

### Status

**Do NOT use as a primary marketing channel.**

This is important, so I’ll be blunt.

### Why Not

- Personal profiles are:
    - Poorly indexed
    - Privacy-gated
    - Algorithmically deprioritized for business discovery
- Mixing personal life with studio identity muddies signal
- You gain almost nothing professionally from pushing this channel

### Recommendation

- Leave the personal Facebook profile alone
- If Facebook is needed later:
    - Create a **Digital Herencia Page**
    - Or a professional Page for Ivan P. Roman
- Otherwise, skip it entirely

You do not need Facebook to win in this lane.
