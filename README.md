# DevNotes

Private Obsidian vault for project memory, product contracts, technical notes, deep research, agent workflows, and source-controlled knowledge operations.

## Purpose

DevNotes is a Git-backed Obsidian vault used as a durable context system for software projects and AI-assisted development.

Primary source document:

- [`PROJECT_SOURCE.md`](PROJECT_SOURCE.md)

Primary vault home note:

- [`devnotes.home.md`](devnotes.home.md)

## Operating Model

Markdown = thinking and explanation
YAML     = structured planning and contracts
JSON     = execution state and logs

### The vault uses:

- numbered top-level folders
- Dendron-style dot notation
- Obsidian properties
- project maps
- contract templates
- Dataview dashboards
- PowerShell automation
- tracked agent operation logs

```

```
