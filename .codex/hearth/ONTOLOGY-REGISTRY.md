# Maximal Template Ontology Registry

These are the nine canonical application ontologies from `3.RESOURCES/template/README.md`.

| Module | Ontology | Representative implementation area |
|---|---|---|
| MOD-001 | CRM / Pipeline Tracker | `app/(tenant)/crm`, CRM actions/fetchers/workflows/schemas/types |
| MOD-002 | Project Management / Task Tracker | `app/(tenant)/projects`, project actions/fetchers/workflows/schemas/types |
| MOD-003 | Customer Support / Ticketing | `app/(tenant)/support` |
| MOD-004 | Marketing Automation & Analytics | `app/(tenant)/marketing` |
| MOD-005 | Invoicing & Expense Tracker | `app/(tenant)/invoices`, `expenses` |
| MOD-006 | Social Media Scheduler | `app/(tenant)/social` |
| MOD-007 | AI-Powered Wrapper / Micro-SaaS | `app/(tenant)/ai` |
| MOD-008 | B2B Client Portal | `app/(tenant)/portal` |
| MOD-009 | Internal Tools / Admin Portal | `app/(tenant)/admin` |

Shared foundation is substrate, not a tenth ontology.
