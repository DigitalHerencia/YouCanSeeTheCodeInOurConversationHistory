# Code Lab Curriculum Contract

## Module model

Each Maximal Template ontology is a Code Lab module.

1. CRM / Pipeline Tracker
2. Project Management / Task Tracker
3. Customer Support / Ticketing
4. Marketing Automation & Analytics
5. Invoicing & Expense Tracker
6. Social Media Scheduler
7. AI-Powered Wrapper / Micro-SaaS
8. B2B Client Portal
9. Internal Tools / Admin Portal

The common Maximal Template foundation is substrate, not a tenth module.

## Lesson model

Each lesson corresponds to one canonical DevCycle from the Notion Dev SOP:

1. Initialization
2. Scaffolding
3. Configuration
4. Verification
5. Data
6. Features
7. Testing
8. Validation
9. Debug
10. Security
11. Performance
12. Observability
13. CI/CD
14. Code Review
15. Documentation
16. Deploy
17. Updates

## Applied learning

The real project is the exercise.

A Code Lab drill is a real TaskNotes task with:
- a learning objective
- pattern target
- acceptance criteria
- execution evidence
- reflection
- confidence
- mastery state

Code Space is the implementation surface.

There is no substitute beginner curriculum.
