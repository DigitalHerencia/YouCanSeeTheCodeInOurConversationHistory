# Hearth Automation Contract

Meta Bind: human state.
Templater: deterministic generation.
QuickAdd: workflow orchestration.
TaskNotes: executable task truth.
Bases: projections.
Hearth: dashboards.
Git: repository provenance.
Code Space: live code.

Project creation:
- generate ID and work code
- create the project folder
- create Project.md, Project Charter.md, Roadmap.md, Project Index.md, Board.md
- create starter milestone/phase/document pack from the selected blueprint
- set project context
- never invent business requirements

Task completion:
- record completion
- reconcile phase/milestone/project progress
- reconcile health and next action
- reconcile explicit provenance
- link outputs created through Hearth output workflows
- never infer an output from the task title

Daily generation:
- Yesterday: completed work, project/phase context, outputs/evidence
- Today: bounded focus projection, due work, next action, full queue link
- blockers
- deadlines/reviews
- scheduled cadence
- current work context
- Zettelkasten/resource review state
- Code Lab state
- relevant Git/vault health

Daily generated regions are replaceable. Human regions are never overwritten.

Cadence is demand-driven. Do not mass-create recurring meeting notes.

All refresh/create operations must be idempotent.
