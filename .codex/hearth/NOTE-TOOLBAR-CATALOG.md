# Note Toolbar Catalog

## Project context
New Milestone; New Phase; New PRD; New Technical Requirements; New ADR; New Task; Create Board; Open Code Lab; Refresh Project.

## Phase context
Add Task; New Requirement; Create Task from Requirement; Phase Review; Open Lesson; Refresh Next Action.

## Document context
Add Requirement; Create Task; Create Evidence; Add Acceptance Criteria; Traceability; Supersede; Archive.

## Resource context
Link to Project; Extract Knowledge; Create Evergreen; Create Pattern; Add to Code Lab; Archive; Restore.

## Daily context
Refresh Rollup; Create Task; Log Blocker; Open current project; Open current Code Lab lesson.

## Code Lab context
Open Code Space; Start Drill; Log Attempt; Log Evidence; Mark Mastery; Review Pattern; Generate Test.

The toolbar should expose commands appropriate to the current note type rather than showing the entire command inventory.
