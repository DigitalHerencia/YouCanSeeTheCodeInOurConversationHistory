# Use the vault

Open Hearth for capture, active projects, learning, and Git. Press **Ctrl+Shift+Space** anywhere for QuickAdd.

## Capture and work

- **Amoeba Capture:** get a thought down. REFACTOR splits it; PROMOTE opens Obsidian's move dialog when it deserves a durable home.
- **New Project:** creates `1.PROJECTS/<name>/Project.md` and `Board.md`. Write the outcome, then plan milestones and workstreams on the board.
- **New Task:** opens TaskNotes. With Project.md open, TaskNotes associates the task with that project. Use its status, priority, scheduling, and completion controls. Tasks live in `1.PROJECTS/_Tasks`.
- **Clipping / AI Thread:** retain source material in ZETTLECASTEN, then extract ideas and link the useful knowledge into your work.
- **Stack Syntax Drill:** write TypeScript or stack syntax from memory, compare with the reference, and record the correction.
- **Daily Note:** record focus, blockers, progress, and carryover. Daily habit checkboxes are observations; project tasks belong in TaskNotes.

## Find and maintain

Hearth Projects shows actual TaskNotes by status. Project notes embed only their own tasks. Kanban cards describe milestones and workstreams; they do not duplicate task status.

Properties describe lifecycle and plugin relationships. Tags classify meaning. Use `archive` to retire or restore a note; automatic task movement and Git sync are off.

Code Space mounts the local code repository under `_mounts/CodependentCoding`. Files there are the actual repository files. Use that repository's own Git workflow for code changes.

Keep Minimal, `reform-core`, and `callouts` enabled. Switch between the seven supplied `mode-*` snippets by enabling exactly one. Your selected fonts and branding are preserved.

Use Hearth Git deliberately for vault commits, fetch, pull, and push.
