# Module Specifications

## LauncherLtd

LauncherLtd is the workspace launcher, target repo browser, recent target hub, and session picker.

### Features

- Select target repo.
- Browse directory tree.
- Open recent repos.
- Open recent sessions.
- Continue last target.
- Enter path manually.
- Validate workspace.
- Detect profile.
- Detect package manager.
- Detect Git repo.
- Detect Node/pnpm versions.
- Create session.
- Continue previous session.
- Detect monorepos.
- Detect workspaces:
  - pnpm workspace
  - npm workspace
  - yarn workspace
  - turborepo
  - nx
- Detect Git root separately from selected folder.
- Detect dirty state.
- Show workspace health score.
- Handle non-Node repos.
- Handle static/docs profiles.
- Support multi-profile workspaces.

### UI Components

- App shell.
- Directory tree.
- File picker.
- Select.
- Menu.
- Data grid.
- Info box.
- Status message.
- Alert.
- Wizard.
- Confirm.
- Scroll view.

### Features

- Target repo summary.
- Git status summary.
- Last verification result.
- Last command result.
- Recent sessions.
- Clipboard intake state.
- Recommended next actions.
- Quick action cards.
- Active job status.
- Notifications.
- Environment strip:
  - node
  - pnpm
  - package name
  - branch
  - dirty/clean state
  - target path
- Dashboard data aggregation.
- Derived state selectors.
- Empty state for no target.
- Error state if repo is unreadable.
- Stale data refresh.
- Background refresh cadence.
- Manual refresh action.
- Job state integration.
- Health score.
- Warning engine:
  - dirty repo
  - missing dependencies

  - package manager mismatch
  - failing tests
  - uncommitted generated files

- Open PreferLtd.
- Paste/parse clipboard.

- Open help.
