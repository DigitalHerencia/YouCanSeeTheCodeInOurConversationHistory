# Metadata and Knowledge Graph Contract

## Tags classify

Tags answer what kind of material this is, what subject it concerns, which semantic facets should retrieve it, and which engineering/domain concepts appear here.

Tags do **not** determine canonical ownership.

## Properties represent useful mutable state

Properties primarily exist when the user or system will actually change them.

### Project

`Status`, `Priority`, `Health`, `Phase`, `Progress`, `Target`, `Next Action`

### Governance

`Status`, `Authority`, `Review State`

### Specification

`Status`, `Priority`, `Implementation State`, `Validation State`

### Decision

`Status`, `Impact`, `Decision Date`

### Research

`Status`, `Confidence`, `Disposition`

### Task

`Status`, `Priority`, `Due`, `Scheduled`, `Project`, `Blocked By`

### Writing

`Stage`, `Publish Status`

## Authority

Use only:

- `Source of Truth`
- `Working`
- `Reference`
- `Derived`
- `Historical`

Authority is distinct from lifecycle state.

The discarded values `canonical`, `supporting`, `implementation-evidence`, `project-specific`, and `operational` are not active aliases and must not be generated by governance, templates, controls, or machine contracts.

## Lifecycle and health

Knowledge:

`Draft → Review → Active → Superseded → Archived`

Work:

`Backlog → Ready → In Progress → Blocked → Done / Cancelled`

Project health:

`On Track / At Risk / Blocked / Paused`

Validation evidence semantics:

`Passed / Failed / Skipped / Blocked / Inferred`

## Typed relationships

Use explicit typed relationships only when the edge itself carries important semantics:

`part_of`, `depends_on`, `implements`, `refines`, `validates`, `evidence_for`, `derived_from`, `supersedes`, `governed_by`, `connects_to`

Internal targets use wikilinks where the storage surface supports them.

## Traceability

The canonical traceability path is:

**source → claim → decision → specification → artifact → validation → evidence**

Links exist because they improve recovery, provenance, navigation, dependency reasoning, or authority—not to inflate graph density.

## Interaction rule

Meta Bind is the ordinary editing surface for mutable state. Routine workflow must not require manual YAML editing.

## Ownership rule

DevNotes stewards metadata, taxonomy, information architecture, retrieval, and the knowledge graph. A tag referring to another discipline does not transfer that discipline's canonical ownership to DevNotes.
