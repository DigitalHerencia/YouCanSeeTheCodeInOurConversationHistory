# Obsidian Kanban Plugin

> Create markdown-backed Kanban boards in Obsidian
---
## Create a Kanban board

To create a new Kanban board, you can:

- Right-click on a folder and select `New Kanban board`.

![Screen Shot 2021-09-15 at 9.14.52 PM.png](https://publish-01.obsidian.md/access/49524b4a7633b05b06c16150ce280be4/Assets/Screen%20Shot%202021-09-15%20at%209.14.52%20PM.png)

- Execute the command palette command, `Kanban: Create new board`, which will create a board at the root of your vault.

![Screen Shot 2021-09-15 at 9.15.11 PM.png](https://publish-01.obsidian.md/access/49524b4a7633b05b06c16150ce280be4/Assets/Screen%20Shot%202021-09-15%20at%209.15.11%20PM.png)

- Or convert an empty file into a Kanban board with the command palette command, `Kanban: Convert empty note to Kanban`.

![Screen Shot 2021-09-15 at 9.15.31 PM.png](https://publish-01.obsidian.md/access/49524b4a7633b05b06c16150ce280be4/Assets/Screen%20Shot%202021-09-15%20at%209.15.31%20PM.png)

## Create notes from cards

Notes can be created from Kanban cards by right clicking on a card, or clicking on the three dots menu on the right side of a card, and selecting `New note from card`.

![Screen Shot 2021-09-13 at 12.29.20 PM.png](https://publish-01.obsidian.md/access/49524b4a7633b05b06c16150ce280be4/Assets/Screen%20Shot%202021-09-13%20at%2012.29.20%20PM.png)

This will create a new note in the [Note folder](https://publish.obsidian.md/kanban/Settings/Note+folder) using the [Note template](https://publish.obsidian.md/kanban/Settings/Note+template) with the card's content as the title. The card will then link to the new note.

![Screen Shot 2021-09-13 at 12.33.39 PM.png](https://publish-01.obsidian.md/access/49524b4a7633b05b06c16150ce280be4/Assets/Screen%20Shot%202021-09-13%20at%2012.33.39%20PM.png)
