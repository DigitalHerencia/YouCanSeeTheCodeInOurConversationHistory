# Codependent Coding™

This folder is the active project workspace for **The Codependent Coding™ Web App Architecture**.

## What this project is

Codependent Coding is the umbrella system that governs the architecture, source-backed building blocks, maximal implementation library, configuration/generation system, generated artifact, public documentation, and Codex execution tooling.

The active project has three evidence/knowledge areas:

- `10.PROJECTS.CODEPENDENTCODING.WebApp-Architecture/` — architecture, product definitions, design/planning, and supporting doctrine.
- `10.PROJECTS.CODEPENDENTCODING.Simples/` — source-backed Simple records, maps, dashboard, canonicalization workflow, and workbench contract.
- `10.PROJECTS.CODEPENDENTCODING.Source Mirror/` — provenance-preserving source evidence. **A mirror is not proof that physical source repositories have already been consolidated.**

`60 CODEPENDENT CODING` remains the durable flat knowledge-system corpus and historical/doctrinal evidence; this folder owns active project evolution.

## Current state

The product model and DevNotes organization are substantially consolidated. The physical software repositories are not: `DigitalHerencia/CodependentCoding` is still the older knowledge-system repository, while the current site/generator ancestry remains in `DigitalHerencia/TheHipsterStack`, and the Maximal Template remains its own implementation repository.

The immediate engineering step is therefore **repository consolidation**, after the remaining terminology/workflow propagation in the canon is closed.
