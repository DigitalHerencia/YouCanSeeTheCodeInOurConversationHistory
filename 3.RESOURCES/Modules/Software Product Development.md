# Software Product Development

A personal rebuild of the Notion product-development pack. The roadmap is the center; milestones, engineering/design work, research, experiments, and analysis link back to project outcomes.

## Core Surfaces

- Roadmap: projects and milestone state
- Kanban: phase/task flow
- Engineering: implementation notes and tasks
- Design: product/UX notes and tasks
- Research: discovery, user research, and evidence
- Experiments: hypotheses, tests, results
- Analysis: metric questions and final reports
- Decisions: consequential choices and rationale

## Use

Start with `SYSTEM/Templates/Project.template.md`, then add only the surfaces the project needs. Do not manufacture team structure for solo work.
