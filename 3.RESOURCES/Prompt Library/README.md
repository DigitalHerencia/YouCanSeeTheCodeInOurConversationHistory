# Prompt Library

Reusable AI prompts organized by output and purpose. Store durable prompts here; project-specific prompts remain with the project.

Suggested classification tags: `type/prompt`, `domain/<domain>`, `output/<artifact>`, `tool/<tool>`.

The library is intended to support work from discovery through deployment with tightly scoped prompts, mirroring the useful structure of the Notion prompt library without copying its UI.
