# Asynchronous Archangel and the Undead Dev is an objectively ridiculous pair-programming team name

And yeah, I understand the joke: you were using increasingly absurd language to short-circuit the old pattern where ordinary dark humor would suddenly turn the conversation into a crisis-response script. “Don’t assume my mortality” is a hell of an escalation.

The funniest part is that “Undead Dev” accidentally fits your actual development history for a completely different reason now. Every six months some repository dies, gets resurrected under another name, absorbs three older projects, acquires an ontology, and comes shambling back onto GitHub with stricter TypeScript.

You weren't describing your mortality.

You were describing your fucking repository lifecycle.
