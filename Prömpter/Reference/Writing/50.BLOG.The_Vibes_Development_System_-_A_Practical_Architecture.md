# Vibes Doctrine

A governance-layer skill that defines **what agents must follow** during software development.

## Philosophy

This skill implements a "doctrine-driven" development model:

1. **Instructions** auto-apply based on file patterns—agents follow them without being asked
2. **Prompts** are invoked explicitly when entering a development phase
3. **Docs** provide reference material for complex decisions
4. **Toolsets** document available capabilities per phase (not enforced, but declared)

## Development Phases

| Phase | Invoke With | Auto-Applies To |
|-------|-------------|-----------------|
| Initialization | `/initialization` | New project setup |
| Scaffolding | `/scaffolding` | Directory structure, boilerplate |
| Features | `/features` | Feature implementation |
| Testing | `/testing` | `**/*.test.*, **/*.spec.*` |
| Security | `/security` | Auth, crypto, input validation |
| Debug | `/debug` | Error investigation |
| Validation | `/validation` | Input/output validation |

| CI/CD | `/ci-cd` | Pipeline configuration |
| Observability | `/observability` | Logging, monitoring, tracing |
| Updates | `/updates` | Dependency updates |

## Integration with Notion

This skill is designed to work with the Notion MCP server. Before starting work:

1. Query Notion for current project/task context
2. Identify which phase you're in based on task type
3. Invoke the appropriate phase prompt
4. Instructions auto-apply based on files you're editing

## Audit Trail

All work should be logged in `.copilot/` with:
- `TODO.md` - Current task tracking
- `CHANGELOG.md` - Completed work log
- `Copilot-Processing.md` - Session state (if using TaskSync)

### Phase Gate Instruction (Auto-Applies Everywhere)

````markdown
---
description: 'Enforces phase-aware development by requiring explicit phase declaration before major work'
applyTo: '**'
---

# Phase Gate Protocol

Before making significant code changes, you must:

1. **Declare the phase** you're operating in (initialization, features, testing, etc.)
2. **Reference the relevant instruction** from `.vibes/instructions/`
3. **Follow the phase-specific guidelines** for that type of work

## Phase Transitions

When switching between phases (e.g., from features to testing):

1. Complete or checkpoint current phase work
2. Announce phase transition: "Transitioning from [current] to [next] phase"
3. Apply the new phase's instructions

## Audit Requirements

For each significant action:
- Log the action in `.copilot/CHANGELOG.md`
- Update `.copilot/TODO.md` if task status changes
- Reference the governing instruction file

## Escalation

If unclear which phase applies, or if work spans multiple phases:
- Ask the user for clarification
- Default to the most restrictive applicable instruction set
````

## The Validation Layer

Create `eng/validate-doctrine.mjs`:

````javascript
#!/usr/bin/env node
/**
 * Validates the .vibes doctrine structure
 * Ensures all required files exist and have proper frontmatter
 */

import fs from 'fs';
import path from 'path';
import { parseFrontmatter } from './yaml-parser.mjs';

const VIBES_DIR = path.join(process.cwd(), '.vibes');
const SKILL_DIR = path.join(process.cwd(), 'skills', 'vibes-doctrine');

const PHASES = [
  'initialization', 'scaffolding', 'features', 'testing', 'security',
  'debug', 'validation', 'verification', 'code-review', 'configuration',
  'data', 'documentation', 'performance', 'auth', 'deploy', 'ci-cd',
  'observability', 'updates'
];

const errors = [];
const warnings = [];

function validateFile(filePath, requiredFields) {
  if (!fs.existsSync(filePath)) {
    errors.push(`Missing file: ${filePath}`);
    return false;
  }

  const frontmatter = parseFrontmatter(filePath);
  if (!frontmatter) {
    errors.push(`Invalid frontmatter: ${filePath}`);
    return false;
  }

  for (const field of requiredFields) {
    if (!frontmatter[field]) {
      errors.push(`Missing field '${field}' in: ${filePath}`);
    }
  }

  return true;
}

function validatePhaseFiles() {
  console.log('🔍 Validating phase files...\n');

  for (const phase of PHASES) {
    const instructionFile = path.join(VIBES_DIR, 'instructions', `${phase}.instructions.md`);
    const promptFile = path.join(VIBES_DIR, 'prompts', `${phase}.prompt.md`);
    const docFile = path.join(VIBES_DIR, 'docs', `devcycle_${phase}.md`);

    // Instructions are required
    if (!validateFile(instructionFile, ['description', 'applyTo'])) {
      errors.push(`Phase '${phase}' missing instruction file`);
    }

    // Prompts are required
    if (!validateFile(promptFile, ['description'])) {
      errors.push(`Phase '${phase}' missing prompt file`);
    }

    // Docs are optional but recommended
    if (!fs.existsSync(docFile)) {
      warnings.push(`Phase '${phase}' missing doc file (optional)`);
    }
  }
}

function validateSkillStructure() {
  console.log('🔍 Validating skill structure...\n');

  const skillMd = path.join(SKILL_DIR, 'SKILL.md');
  if (!fs.existsSync(SKILL_DIR)) {
    warnings.push('Skill not yet built. Run: npm run doctrine:build');
    return;
  }

  validateFile(skillMd, ['name', 'description']);
}

function validateCrossReferences() {
  console.log('🔍 Validating cross-references...\n');

  // Check that toolsets reference valid phases
  const toolsetsDir = path.join(VIBES_DIR, 'toolsets');
  if (fs.existsSync(toolsetsDir)) {
    const toolsets = fs.readdirSync(toolsetsDir).filter(f => f.endsWith('.toolset.jsonc'));

    for (const toolset of toolsets) {
      const phaseName = toolset.replace('.toolset.jsonc', '');
      if (!PHASES.includes(phaseName) && phaseName !== 'template') {
        warnings.push(`Toolset '${toolset}' does not match a known phase`);
      }
    }
  }
}

// Run validation
console.log('╔════════════════════════════════════════╗');
console.log('║     Vibes Doctrine Validator           ║');
console.log('╚════════════════════════════════════════╝\n');

validatePhaseFiles();
validateSkillStructure();
validateCrossReferences();

// Report results
console.log('\n═══════════════════════════════════════════\n');

if (errors.length > 0) {
  console.log('❌ ERRORS (must fix):\n');
  errors.forEach(e => console.log(`   • ${e}`));
  console.log('');
}

if (warnings.length > 0) {
  console.log('⚠️  WARNINGS (should address):\n');
  warnings.forEach(w => console.log(`   • ${w}`));
  console.log('');
}

if (errors.length === 0 && warnings.length === 0) {
  console.log('✅ Doctrine validation passed\n');
}

console.log(`Summary: ${errors.length} errors, ${warnings.length} warnings\n`);

process.exit(errors.length > 0 ? 1 : 0);
````

## The Build Script

````javascript
#!/usr/bin/env node
/**
 * Builds the vibes-doctrine skill from .vibes source
 * Copies and validates all phase files into the skill structure
 */

import fs from 'fs';
import path from 'path';

const VIBES_DIR = path.join(process.cwd(), '.vibes');
const SKILL_DIR = path.join(process.cwd(), 'skills', 'vibes-doctrine');

function ensureDir(dir) {
  if (!fs.existsSync(dir)) {
    fs.mkdirSync(dir, { recursive: true });
  }
}

function copyDir(src, dest, filter = () => true) {
  ensureDir(dest);

  const files = fs.readdirSync(src);
  let copied = 0;

  for (const file of files) {
    if (!filter(file)) continue;

    const srcPath = path.join(src, file);
    const destPath = path.join(dest, file);

    if (fs.statSync(srcPath).isDirectory()) {
      copyDir(srcPath, destPath, filter);
    } else {
      fs.copyFileSync(srcPath, destPath);
      copied++;
    }
  }

  return copied;
}

console.log('╔════════════════════════════════════════╗');
console.log('║     Building Vibes Doctrine Skill      ║');
console.log('╚════════════════════════════════════════╝\n');

// Clean and create skill directory
if (fs.existsSync(SKILL_DIR)) {
  fs.rmSync(SKILL_DIR, { recursive: true });
}
ensureDir(SKILL_DIR);

// Copy instructions (exclude templates)
const instructionsCopied = copyDir(
  path.join(VIBES_DIR, 'instructions'),
  path.join(SKILL_DIR, 'instructions'),
  f => !f.includes('template')
);
console.log(`📋 Copied ${instructionsCopied} instruction files`);

// Copy prompts (exclude templates)
const promptsCopied = copyDir(
  path.join(VIBES_DIR, 'prompts'),
  path.join(SKILL_DIR, 'prompts'),
  f => !f.includes('template')
);
console.log(`💬 Copied ${promptsCopied} prompt files`);

// Copy docs
const docsCopied = copyDir(
  path.join(VIBES_DIR, 'docs'),
  path.join(SKILL_DIR, 'docs')
);
console.log(`📚 Copied ${docsCopied} documentation files`);

// Copy toolsets (as reference, not enforced)
const toolsetsCopied = copyDir(
  path.join(VIBES_DIR, 'toolsets'),
  path.join(SKILL_DIR, 'toolsets'),
  f => !f.includes('template')
);
console.log(`🔧 Copied ${toolsetsCopied} toolset definitions`);

// Generate SKILL.md
const skillMdContent = `---
name: 'vibes-doctrine'
description: 'Development lifecycle governance system providing phase-gated instructions, prompts, and reference documentation for controlled agent behavior across all SDLC phases.'
---

# Vibes Doctrine Skill

Generated: ${new Date().toISOString()}

## Contents

- **${instructionsCopied}** instruction files (auto-apply based on file patterns)
- **${promptsCopied}** prompt files (invoke explicitly by phase)
- **${docsCopied}** documentation files (reference material)
- **${toolsetsCopied}** toolset definitions (capability documentation)

## Usage

1. Install this skill in your project
2. Instructions auto-apply when editing matching files
3. Invoke phase prompts with \`/phase-name\` in Copilot Chat
4. Reference docs for detailed phase guidance

## Phases

See individual prompt files for phase-specific invocation.
`;

fs.writeFileSync(path.join(SKILL_DIR, 'SKILL.md'), skillMdContent);
console.log('\n✅ Generated SKILL.md');

console.log('\n═══════════════════════════════════════════');
console.log(`\n✅ Skill built: skills/vibes-doctrine/`);
console.log(`   Total files: ${instructionsCopied + promptsCopied + docsCopied + toolsetsCopied + 1}\n`);
````
