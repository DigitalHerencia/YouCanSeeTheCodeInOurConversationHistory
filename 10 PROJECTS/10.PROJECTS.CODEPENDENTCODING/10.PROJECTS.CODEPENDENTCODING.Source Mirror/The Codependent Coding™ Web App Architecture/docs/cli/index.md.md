# CLI reference

The canonical executable is `hipster-stack`. The published package remains `hipster-stack` and also exposes that binary for initializer compatibility; no npm package rename is implied.

- [`create`](/docs/cli/create) generates a project.
- [`add`](/docs/cli/add) adds one supported owned surface.
- [`explain`](/docs/cli/explain) summarizes generated provenance.
- [`doctor`](/docs/cli/doctor) diagnoses local readiness.
- `hipster-stack --version` prints the CLI version.
