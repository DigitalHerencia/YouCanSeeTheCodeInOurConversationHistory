**Priority:** P1  
**Phase:** Public Site  
**Task status:** Backlog

## Outcome

Complete the dark industrial landing page using the supplied visual assets, mandatory hero copy, product-system explanation, and restrained cultural voice.

## Why This Exists

The website spec defines colors, typography roles, hero copy, banner treatment, and asset usage; screenshots already establish the direction.

## Execution Checklist

- [ ] Use black/`#05030b` background and restrained `#2f7a8d` signal treatment.
- [ ] Use supplied crown/wordmark/banner assets with responsive sizing.
- [ ] Keep Copperplate-like display role, JetBrains Mono body, Fira Code code with build-safe fallbacks.
- [ ] Use mandatory hero thesis and Hipster Stack tagline.
- [ ] Explain the system in a concise sequence rather than dumping every coined term above the fold.
- [ ] Lead users toward exploration/configuration rather than authentication.
- [ ] Add selected attitude/musing lines as seasoning, not structural explanation.
- [ ] Check responsive/mobile composition, contrast, motion, and footer-over-background behavior.

## Acceptance Criteria

- [ ] Landing page matches the written visual contract.
- [ ] Product-system meaning is understandable without reading docs first.
- [ ] Humor supports rather than obscures the product story.
- [ ] Mobile and desktop remain intentional.
