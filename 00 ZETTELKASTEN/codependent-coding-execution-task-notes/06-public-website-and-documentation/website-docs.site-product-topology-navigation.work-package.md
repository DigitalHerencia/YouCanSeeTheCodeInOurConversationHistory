# Unify Website Navigation Around the New Product Topology

**Priority:** P0  
**Phase:** Information Architecture  
**Task status:** Backlog

## Outcome

Make the public site clearly communicate how Codependent Coding, Hipster Stack, Maximal Template, Simples, Ontologies, Constituter, Ordinary Object, and Loaded Vibes relate.

## Why This Exists

The visual/site spec defines brand identities while the master provides the authoritative topology. Visitors should not have to reverse-engineer the relationships from names.

## Execution Checklist

- [ ] Define top-level site navigation and route ownership.
- [ ] Ensure Codependent Coding is presented as the umbrella architecture.
- [ ] Present Hipster Stack as technology/generator/CLI system.
- [ ] Present Maximal Template as the runnable domain-library superset.
- [ ] Present Simples and Ontologies as supported library/preset concepts.
- [ ] Present The Constituter as the configuration workbench.
- [ ] Present Loaded Vibes as the Codex plugin.
- [ ] Use one concise ecosystem diagram on the landing/docs surfaces.
- [ ] Remove older product-role descriptions that contradict the topology.

## Acceptance Criteria

- [ ] A new visitor can explain the system relationships after the landing page.
- [ ] Navigation labels match canonical product roles.
- [ ] No active public copy describes Loaded Vibes as the generator.
