```bash
user@machine:~/project$
```

then you're almost certainly **inside WSL (Windows Subsystem for Linux)** already.

Quick checks:

### From the shell with the `$` prompt

Run:

```bash
uname -a
```

If you see something like:

```text
Linux DESKTOP-XXXXX ... microsoft-standard-WSL2
```

you're in WSL2.

Or:

```bash
cat /proc/version
```

You'll usually see:

```text
Microsoft
WSL
```

in the output.

### From PowerShell

Check installed WSL distributions:

```powershell
wsl --list --verbose
```

Example:

```text
  NAME            STATE           VERSION
* Ubuntu          Running         2
```

If it says `Running`, WSL is currently active.

### Check WSL status

```powershell
wsl --status
```

Example:

```text
Default Distribution: Ubuntu
Default Version: 2
```

### See all running WSL instances

```powershell
wsl --list --running
```

Example:

```text
Ubuntu
```

### If nothing is running

Start your distro:

```powershell
wsl
```

or

```powershell
wsl -d Ubuntu
```

### If you're not sure whether you're in PowerShell or WSL

Run:

```bash
pwd
```

If you get:

```text
/home/ivan
```

that's Linux/WSL.

If you run:

```powershell
Get-Location
```

and it works, you're in PowerShell.

If `Get-Location` throws an error but `ls`, `pwd`, and `apt` work, you're in Linux.

Also, the `$` is unfortunately just the Linux shell prompt. It doesn't indicate your net worth. Linux has been mocking developers with that joke since the 1970s.
