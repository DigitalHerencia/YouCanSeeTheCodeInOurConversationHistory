# Status Report

## Verdict

The Project system now has a coherent eight-role operating model. The main changes are role-boundary cleanup, source pruning, two new Projects, and an explicit cross-Project authority/handoff model. No additional Product, Design, Marketing, or orchestration Project is recommended at this time.

## Existing Projects

### Prömpter
Status: retain, minor source cleanup.

The role already matched the user's intent. The major change is removing the conflicting Prompt Builder agent as a controlling persistent source and keeping prompt technique without mandatory research/test theater.

### Trust Issues
Status: retain, sharpen scope.

The Project now explicitly checks whether material evidence could actually detect failure, including tautological/vacuous/always-green tests, while prohibiting unrelated compliance/performance/code-review scope expansion. The Stupid Lesson is primary doctrine.

### Execution
Status: rewrite completed.

The previous "principal engineering advisor" identity did not sufficiently express the real requirement: backup Codex. The new instructions make implementation and the GitHub Issue -> branch -> PR -> checks/review -> merge -> read-back lifecycle the primary job, using the user's Codex Delivery Instructions as canonical workflow.

### Vibes
Status: retain, re-center.

Vibes is now explicitly the platform/system expert: Codependent Coding + Loaded Vibes + Hipster Stack, architecture/governance, CI/CD, tooling, configuration, provider/deployment mechanics and deep troubleshooting. GitHub project management is a capability, not the whole identity.

### DevNotes
Status: retain, small functional extension.

The live private repository is already well aligned. The Project is reframed as institutional memory for future agents/sessions, and knowledge-graph maintenance is explicitly added without turning backlink counts into a KPI.

### Fuck You Pay Me
Status: major source cleanup.

The instructions were directionally correct, but the persistent source corpus was badly misaligned. The new model centers RevOps/business ops: sales/CRM/outreach, invoices/AR/AP, finance/admin, correspondence and follow-up. Software/portfolio archives should leave persistent context.

## New Projects

### Data Modeler
Status: create.

This role is justified by a real recurring boundary: domain semantics and persistence design precede implementation. It owns conceptual/logical modeling, Prisma/Postgres/Neon, migrations, selects, DTO mapping and transactional invariants.

### Chief of Staff
Status: create.

This role owns time/attention rather than technical orchestration. It manages Scheduled Tasks, reminders, calendar cadence, priorities, follow-ups and routine recovery. The Plus active-task limit makes task-slot budgeting part of the role.

## System-level decisions

- User remains orchestrator.

- Do not create dedicated Product, Design or Marketing Projects yet.
