# Build The Loaded Vibes™ Codex Plugin

## Checklist

- [ ] Extract useful prototype capabilities: repo inspection, context acquisition, architecture classification, bounded execution, validation, environment inspection, Git/GitHub delivery, and handoff.
- [ ] Define a small plugin package architecture.
- [ ] Create only genuinely distinct agents/skills; prefer one universal workflow over simulated engineering departments.
- [ ] Add architecture validators for stable machine-checkable boundaries.
- [ ] Add proportional plugin smoke tests.
- [ ] Add developer-environment inspection assets where they prove real state.
- [ ] Remove/retire obsolete GenAIScript, `src/**`, `.loaded-vibes`, fake capability-enforcement, and 18-phase machinery.
- [ ] Verify operation against a generated Arrangement™.
